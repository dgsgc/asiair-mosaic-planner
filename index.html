      Straight to the Star Adventurer controller

      Sends the panels and the first Light line over your WiFi. It only stores the plan: nothing moves or shoots until you start it on the controller’s page. Works when the planner is opened from your computer (http://localhost) on the controller’s network.

      With a send file

      Save a file and load it on the controller’s page.

      With the ASIAIR Plan Sender app

      Save a send file, then open it in the Plan Sender with the ASIAIR app open. Each target becomes its own ASIAIR plan, exposures included. Or get the Mac app, which sends straight from the planner (free, Mac with Apple silicon).

      By hand in the ASIAIR app

      Copy the panels, then paste them with Import in the ASIAIR app’s plan.

      Show the text
      How to load it into the ASIAIR app
      1. In the ASIAIR app, open Plan and make or open the plan you want. Pasting adds targets to the open plan.
      2. Tap Import and paste. Each panel becomes a target, named like “NGC 7000_1-2”.
      3. The app can’t take exposures from pasted text, so open one panel, add the exposure lines shown here, then use its copy button: “Copy Schedule to All”.
      4. Before the first night, plate-solve one frame and set the camera angle to match the angle here. The ASIAIR doesn’t store an angle for pasted targets.

      The text is in the ASIAIR app’s own format (the one its Share button writes), J2000.
